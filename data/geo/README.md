# ไฟล์ขอบเขตโซน

วางไฟล์ชื่อ `zones.geojson` ในโฟลเดอร์นี้ แล้วแผนที่จะวาดเส้นแบ่งโซนให้อัตโนมัติ

- ต้องเป็น GeoJSON FeatureCollection ของ Polygon/MultiPolygon
- ควรมี property ชื่อ `name` (หรือ `NAME_2`) เพื่อให้แสดง tooltip ตอนชี้เมาส์
- ถ้าไม่มีไฟล์นี้ แผนที่ยังทำงานปกติ แค่ไม่มีเส้นแบ่งโซน

แหล่งข้อมูลขอบเขตการปกครองไทยมีเผยแพร่สาธารณะหลายที่
เลือกเฉพาะจังหวัดที่อยู่ใน tier 1 ก่อน เพราะไฟล์ทั้งประเทศใหญ่และทำให้แผนที่หน่วง
